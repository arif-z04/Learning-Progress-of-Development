---

# 1. Time Management Rules

## Normal mode — 12–15 hours/week

| Day | Time | Focus |
|---|---:|---|
| Monday | 1.5h | Learn fundamentals |
| Tuesday | 2h | Practical coding |
| Wednesday | 1.5h | Learn fundamentals |
| Thursday | 2h | Project development |
| Friday | 2h | Code review and testing |
| Saturday | 3h | Deep development session |
| Sunday | 2h | System design + weekly review |
| **Total** | **14h** | |

## Exam mode — 4–6 hours/week

When semester exams are approaching:

| Day | Time | Focus |
|---|---:|---|
| Monday | 30m | Review previous topics |
| Tuesday | 1h | Supervise AI project progress |
| Wednesday | — | Semester preparation |
| Thursday | 1h | Review generated code |
| Friday | — | Semester preparation |
| Saturday | 1.5h | Essential project tasks |
| Sunday | 1h | Weekly review and next-week planning |
| **Total** | **5h** | |

### Exam protection rules

- [ ] Semester preparation takes priority.
- [ ] Do not introduce new technologies during exam-heavy weeks.
- [ ] Never sacrifice sleep to complete roadmap tasks.
- [ ] Reduce project scope instead of increasing study hours.
- [ ] Use AI agents for repetitive implementation, but personally review important changes.
- [ ] If an exam is within 48 hours, pause optional development work.
- [ ] Missed tasks move to the next available week; don't overload the following day.

---

# 2. Daily Engineering Routine

Use this routine whenever you have a development session.

- [ ] Identify the specific task before starting.
- [ ] Understand the concept before asking AI to implement it.
- [ ] Review the implementation plan.
- [ ] Inspect generated code and changed files.
- [ ] Run the application and tests.
- [ ] Investigate errors rather than blindly asking AI to fix them.
- [ ] Record what you learned.
- [ ] Commit working changes to Git.

# 5. Exam Mode — Emergency Workload Reduction

Whenever semester exams become intense, switch to this reduced plan.

### Minimum weekly commitments

- [ ] 1 hour: Review an existing fundamental topic.
- [ ] 1 hour: Inspect AI-generated project changes.
- [ ] 1 hour: Run project tests and check critical bugs.
- [ ] 1 hour: Review architecture or security notes.
- [ ] 1 hour: Plan the next available development week.

**Optional:** An additional hour for project supervision.

### Exam-week priorities

1. Semester finals.
2. Sleep and recovery.
3. Essential project deadlines.
4. Short technical revision.
5. Optional advanced learning — paused.

Do not try to compensate for an exam-heavy week by doubling the following week's workload.
